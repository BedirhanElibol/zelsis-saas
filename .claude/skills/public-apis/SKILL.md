# Public APIs Skill

This skill provides a curated list of free, high-quality public APIs that can be integrated into projects. It is useful for rapid prototyping, adding features without backend development, and finding data sources.

## How to Use

1.  **Browse Resources**: Check `resources/public_apis_list.md` for a categorized list of APIs.
2.  **Select API**: Identify an API that fits your feature requirement (e.g., Weather, Currency, Geocoding).
3.  **Integration**: Use `fetch()` or `axios` in your project to consume these APIs.

## Categories Included

-   **Authentication & Security**: Email validation, IP info.
-   **Development**: Placeholders, Code generation.
-   **Data & Info**: Weather, Countries, Finance.
-   **Media**: Images, Music, Video.
-   **Lifestyle**: Health, Food, Travel.

## Notes

-   Some APIs may require an API Key. This is noted in the 'Auth' column.
-   Always check the official documentation for the latest usage limits and terms.
